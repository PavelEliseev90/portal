# Варианты внесения диагностики механиком в интерактивную оценку

## 🎯 Цель
Предложить различные варианты организации внесения диагностической информации механиком, начиная с самых простых и удобных.

---

## 📊 Текущая структура

### Где хранится диагностика:
1. **`RegInteractivOcenkaTestDrive`** - основные поля диагностики:
   - `engine`, `gear`, `brake`, `suspension`, `system_og`, `wheel`, `conditioner`, `turbo`, `drive`, `to`
   - Комментарии для каждой системы (`comment_engine`, `comment_gear` и т.д.)
   - Статусы: 0 - не работает, 1 - работает, 2 - есть замечания, 10 - не проверено

2. **`RegInteractivOcenkaSoglasovanie.comment_diagnostica`** - общий комментарий после диагностики

3. **`DiagnosticReferenceSelection`** - связь с элементами справочника диагностики

4. **`RegRegInteractivOcenkaFiles`** с `type_file='diagnostic'` - файлы диагностики

5. **`RegInteractivOcenka.date_diagnostic`** - дата проведения диагностики

## 🚀 Варианты внесения диагностики (от простого к сложному)

### **ВАРИАНТ 1: QR-код для быстрого доступа** ⭐⭐⭐ (САМЫЙ ПРОСТОЙ)

**Суть:** Механик сканирует QR-код на автомобиле или в задании и попадает сразу на форму диагностики.

**Реализация:**
- Генерация QR-кода для каждой оценки (`RegInteractivOcenka.qr` уже есть!)
- QR-код ведет на специальную упрощенную страницу: `/estimation/<slug>/diagnostic/quick/`
- Страница открывается без авторизации (или с простой авторизацией по токену)
- Только поля диагностики, без лишних элементов

**Преимущества:**
- ✅ Очень быстро - 1 клик (сканирование)
- ✅ Не нужно искать оценку в системе
- ✅ Работает на любом смартфоне
- ✅ Можно распечатать QR-код и прикрепить к автомобилю

**Недостатки:**
- ⚠️ Нужен смартфон с камерой
- ⚠️ Нужен доступ в интернет

**Пример URL в QR-коде:**
```
https://ah.kors-group.com/estimation/abc123/diagnostic/quick/?token=xyz789
```

**Интерфейс:**
- Большие кнопки для каждой системы (Двигатель, КПП, Тормоза и т.д.)
- Цветовая индикация: 🟢 Работает / 🟡 Замечания / 🔴 Не работает
- Поле для комментария под каждой системой
- Кнопка "Сохранить" внизу

### **ВАРИАНТ 4: Голосовой ввод** ⭐⭐

**Преимущества:**

- ⚠️ Может быть неточным распознавание
- ⚠️ Нужна тишина или хороший микрофон

**Пример использования:**

### 1. QR-код для быстрого доступа

**Генерация QR-кода:**
```python
# В модели RegInteractivOcenka уже есть поле qr
# Нужно генерировать QR при создании/обновлении оценки

import qrcode
from io import BytesIO
from django.core.files.base import ContentFile

def generate_diagnostic_qr(estimation):
    url = f"https://ah.kors-group.com/estimation/{estimation.slug}/diagnostic/quick/?token={estimation.access_token}"
    qr = qrcode.QRCode(version=1, box_size=10, border=5)
    qr.add_data(url)
    qr.make(fit=True)
    img = qr.make_image(fill_color="black", back_color="white")
    
    buffer = BytesIO()
    img.save(buffer, format='PNG')
    estimation.qr.save(f'diagnostic_{estimation.id}.png', ContentFile(buffer.getvalue()), save=False)
```

**Токен доступа:**
```python
# Добавить поле в RegInteractivOcenka
access_token = models.CharField('Токен доступа', max_length=64, unique=True, blank=True, null=True)

# Генерировать при создании
import secrets

```

**URL для быстрого доступа:**

### 3. Чек-лист с типовыми проблемами

**Использование справочника диагностики:**
```python
# В view
def diagnostic_quick(request, slug):
    estimation = get_object_or_404(RegInteractivOcenka, slug=slug)
    
    # Получаем категории и элементы справочника
    categories = DiagnosticReferenceCategory.objects.filter(is_active=True).order_by('order')
    
    diagnostic_data = {}
    for category in categories:
        items = DiagnosticReferenceItem.objects.filter(
            category=category, 
            is_active=True
        ).order_by('order')
        diagnostic_data[category.code] = {
            'category': category,
            'items': items
        }
    
    return render(request, 'register/diagnostic_quick.html', {
        'estimation': estimation,
        'diagnostic_data': diagnostic_data
    })
```

### 4. Голосовой ввод

**JavaScript для распознавания речи:**
```javascript
let recognition;

function startVoiceInput(category) {
    if (!('webkitSpeechRecognition' in window)) {
        alert('Голосовой ввод не поддерживается');
        return;
    }
    
    recognition = new webkitSpeechRecognition();
    recognition.lang = 'ru-RU';
    recognition.continuous = false;
    recognition.interimResults = false;
    
    recognition.onresult = function(event) {
        const text = event.results[0][0].transcript;
        processVoiceCommand(category, text);
    };
    
    recognition.start();
}

function processVoiceCommand(category, text) {
    // Простая обработка команд
    if (text.includes('работает нормально') || text.includes('в порядке')) {
        setStatus(category, 1);
    } else if (text.includes('замечания') || text.includes('проблема')) {
        setStatus(category, 2);
    } else if (text.includes('не работает') || text.includes('сломан')) {
        setStatus(category, 0);
    }
    
    // Сохраняем текст как комментарий
    document.getElementById(`comment_${category}`).value = text;
}
```

## 🔐 Безопасность

### Для QR-кода с токеном:
- Токен генерируется один раз при создании оценки
- Токен можно регенерировать при необходимости
- Доступ только на чтение/запись диагностики
- Логирование всех действий

### Для мобильной страницы:
- Авторизация через токен или сессию
- Ограничение доступа только к диагностике
- Защита от CSRF

## 📊 Метрики успеха

- Время заполнения диагностики: < 5 минут
- Процент заполненных диагностик: > 90%
- Удобство использования: оценка механиков > 4/5
- Количество ошибок при заполнении: < 5%
