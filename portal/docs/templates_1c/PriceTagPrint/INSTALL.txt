СБОРКА ВНЕШНЕЙ ОБРАБОТКИ «Печать ценника КорсАвто»
=================================================

Папка содержит исходники внешней обработки 1С:Предприятие 8.3 для печати HTML-ценника
(тот же макет, что на портале в car_new.html).

Структура:
  PriceTagPrint/
    ПечатьЦенника.xml                          — корневой файл метаданных
    ПечатьЦенника/
      Ext/ObjectModule.bsl                     — регистрация обработки
      Forms/Форма/Ext/Form/Module.bsl          — логика формы и печати
      Templates/МакетЦенника/Ext/Template/Template.txt — HTML-макет

СПОСОБ 1 — БЫСТРАЯ СБОРКА В КОНФИГУРАТОРЕ (рекомендуется)
---------------------------------------------------------

1. Откройте 1С в режиме «Конфигуратор» (или EDT).

2. Файл → Новый → Внешняя обработка.
   Имя: ПечатьЦенника
   Синоним: Печать ценника КорсАвто

3. Добавьте макет:
   - Имя: МакетЦенника
   - Тип: Текстовый документ
   - Скопируйте содержимое из:
     Templates/МакетЦенника/Ext/Template/Template.txt
     (или из price_tag_print.html)

4. Создайте управляемую форму «Форма» (основная форма обработки).

5. На форме добавьте реквизиты (тип «Строка», кроме указанных):

   Марка
   Модель
   Цена                    — Число, 15.0
   ЦенаРезерв              — Булево
   ГодВыпуска
   Пробег
   Двигатель
   ТипДвигателя
   КоробкаПередач
   Привод
   Кузов
   Цвет
   ЛоготипМарки            — URL картинки марки
   QRКод                   — URL или data:image/png;base64,...
   КартинкаТрейдИн
   КартинкаСтрахование
   КартинкаЮрЛица
   КартинкаКредит
   Подразделение
   Сайт
   Телефон
   БазовыйПутьКартинок     — базовый URL для иконок услуг

6. Добавьте команды формы:
   - Печать          → кнопка «Печать»
   - Предпросмотр    → кнопка «Предпросмотр»
   - ЗаполнитьПример → кнопка «Заполнить пример»
   - ОбновитьКартинкиУслуг → «Обновить пути картинок»

7. Вставьте код:
   - Модуль объекта  ← Ext/ObjectModule.bsl
   - Модуль формы    ← Forms/Форма/Ext/Form/Module.bsl

8. Укажите форму «Форма» как форму по умолчанию обработки.

9. Сохраните как файл .epf (Файл → Сохранить как…).

СПОСОБ 2 — ЗАГРУЗКА ИЗ ФАЙЛОВ
------------------------------

1. Конфигуратор → Файл → Открыть → указать ПечатьЦенника.xml
   (или «Загрузить конфигурацию из файлов» на каталог PriceTagPrint)

2. Если форма не загрузилась — выполните шаги 4–7 из способа 1.

ИСПОЛЬЗОВАНИЕ
-------------

1. Откройте .epf через «Файл → Открыть» или подключите как доп. обработку.

2. Заполните поля (или «Заполнить пример» для проверки).

3. «Печать» / «Предпросмотр» → откроется HTML в браузере → Ctrl+P.

4. Для автозаполнения из вашего справочника автомобилей добавьте в модуль формы
   процедуру ЗаполнитьИзАвтомобиля() — заготовка в конце Module.bsl.

ПАРАМЕТРЫ МАКЕТА
----------------

В HTML используются плейсхолдеры [Марка], [Модель], [Цена] и т.д.
Подстановка выполняется автоматически в функции СформироватьHTML().

Картинки услуг по умолчанию (если поля пустые):
  {БазовыйПутьКартинок}/tradein.png
  {БазовыйПутьКартинок}/strah.png
  {БазовыйПутьКартинок}/yur.png
  {БазовыйПутьКартинок}/credit.png

По умолчанию БазовыйПутьКартинок = https://ah.kors-group.com/media/images

QR-код: если поле QRКод пустое, блок QR на ценнике скрывается.

ЦенаРезерв = Истина → цена отображается оранжевым (резерв).

ТРЕБОВАНИЯ
----------

- Платформа 8.3.10+
- Тонкий/толстый клиент с возможностью ЗапуститьПриложение() (открытие браузера)
- Доступ к URL картинок при печати (интернет или локальные file:/// пути)
