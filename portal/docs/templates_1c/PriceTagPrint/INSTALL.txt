СБОРКА ВНЕШНЕЙ ОБРАБОТКИ «Печать ценника КорсАвто»
=================================================

Внешняя обработка 1С:Предприятие 8.3 — печать ценника через табличный документ
(стандартный механизм Показать / Напечатать, без браузера).

Структура:
  PriceTagPrint/
    ПечатьЦенника.xml                          — корневой файл метаданных
    ПечатьЦенника/
      Ext/ObjectModule.bsl                     — регистрация обработки
      Forms/Форма/Ext/Form/Module.bsl          — формирование табличного документа
      Forms/Форма/Ext/Form.xml                 — форма с полями

СБОРКА В КОНФИГУРАТОРЕ
----------------------

1. Файл → Новый → Внешняя обработка.
   Имя: ПечатьЦенника
   Синоним: Печать ценника КорсАвто

2. Создайте управляемую форму «Форма» (основная форма обработки).

3. Реквизиты формы (тип «Строка», кроме указанных):

   Марка, Модель
   Цена                    — Число, 15.0
   ЦенаРезерв              — Булево (оранжевая цена при резерве)
   ГодВыпуска, Пробег, Двигатель, ТипДвигателя
   КоробкаПередач, Привод, Кузов, Цвет
   ЛоготипМарки            — путь к локальному файлу картинки
   QRКод                   — зарезервировано (см. УстановитьQRКод в модуле)
   КартинкаТрейдИн, КартинкаСтрахование, КартинкаЮрЛица, КартинкаКредит
   Подразделение, Сайт, Телефон
   БазовыйПутьКартинок     — папка с иконками услуг (локальный путь)

4. Команды формы:
   Печать, Предпросмотр, ЗаполнитьПример, ОбновитьКартинкиУслуг

5. Вставьте код:
   - Модуль объекта  ← Ext/ObjectModule.bsl
   - Модуль формы    ← Forms/Форма/Ext/Form/Module.bsl

6. Сохраните как .epf

ИСПОЛЬЗОВАНИЕ
-------------

1. Заполните поля (или «Заполнить пример»).
2. «Предпросмотр» → стандартное окно табличного документа 1С.
3. «Печать» → диалог выбора принтера.

КАРТИНКИ
--------

Табличный документ загружает картинки только с локального диска.
Скопируйте всю папку images\ в общий каталог, например:
  C:\KorsAuto\images\

В поле «Базовый путь картинок» укажите этот каталог.

Файлы в images\:
  logo_korsavto.png   — шапка слева (КорсАвто / автомобили с пробегом)
  logo_korsgroup.png  — шапка справа (КорсГрупп / автомобильный холдинг)
  tradein.png, strah.png, yur.png, credit.png — иконки услуг (с портала)

Пересоздать логотипы шапки:
  python images\generate_header_logos.py

QR-КОД (ЗАГЛУШКА)
-----------------

В модуле формы процедура УстановитьQRКод() выводит рамку с текстом [ QR-код ].
Подставьте свою картинку в этой процедуре — пример в комментариях внутри неё.
Поле формы QRКод можно использовать как источник пути/данных.

ДОРАБОТКА МАКЕТА
----------------

Вёрстка собрана программно в Module.bsl (процедуры ВывестиШапкуЦенника,
ВывестиЗаголовокИЦену и т.д.). При необходимости можно:
  - подправить размеры/шрифты в коде;
  - вынести макет в конфигураторе как «Табличный документ» с именованными
    областями и заменить код на Макет.ПолучитьОбласть() + ТабДок.Вывести().

Эталон дизайна (HTML портала): ../price_tag_print.html

ТРЕБОВАНИЯ: платформа 8.3.10+, тонкий или толстый клиент.
