# Приёмка и отправка второго комплекта колёс (2КК)

Пользовательская страница в портале: [/estimations/kolesa-reception/help/](/estimations/kolesa-reception/help/)

## Назначение

Если в интерактивной оценке отмечен **второй комплект колёс**, на складе оформляется
отдельная **приёмка 2КК**: проверка данных, фото и отправка документа в базу **БУ колёс (1С)**.

## Ссылки

| Что | URL |
|-----|-----|
| Список приёмок | `/estimations/kolesa-reception/` |
| Инструкция | `/estimations/kolesa-reception/help/` |

| Карточка приёмки | `/estimations/kolesa-reception/<reception_id>/` |
| АСП (вход) | карточка «Приёмка 2КК на складе» |

## Порядок работы

1. **В оценке** (страница «Колёса») отметить «Оценка со вторым комплектом колес» и заполнить параметры.
2. **Список** `/estimations/kolesa-reception/` — найти оценку со значком 2КК (по умолчанию статус «АМ принят»).
3. **Создать** приёмку — данные копируются из оценки.
4. **Проверить / сохранить** параметры и загрузить фото.
5. **Отправить** в базу БУ колёс.
6. На карточке появятся статус «Отправлен», **номер**, **дата** и **УИН** документа из ответа 1С.

## Ограничения

- Создать приёмку можно только при `kolesa2_estimation = 1` в оценке.
- После отправки нельзя менять поля и удалять фото.
- Повторная отправка запрещена; сброс — только суперпользователь.

## Технически

- Отправка: `send_kolesa_reception_to_1c` → `POST http://k01srv1c08/rwheels2024/hs/mb`, `Type=kolesa_reception`.
- Ответ 1С: `Data.Уин`, `Data.Номер`, `Data.Дата` → поля `send_wheels_ib_uin` / `_number` / `_date`.
- Payload: `build_kolesa_reception_send_payload` (`eco/reception.py`).
