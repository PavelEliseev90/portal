## 🏗️ Общая архитектура системы

### Основные модели данных

**RefCarsOrganization** - центральная модель автомобиля организации:
- Базовые данные: VIN, марка, модель, модификация, год, пробег, цвет
- Технические характеристики: тип кузова, двигатель, КПП, привод, объем, мощность
- Финансовые данные: цена, себестоимость, расходы, БЦП
- Статусы: статус автомобиля, тип продажи, тип приема, вариант управления ценой
- Связи: подразделение, склад, организация, лист оценки (DocLO)
- Аналитика: дни на складе, рейтинг привлекательности, этап УС, ценовая категория
- Интеграции: ссылки на Авто.ру, Авито, Drom, Автотеку

**Документы:**
- `DocRLK` - Рабочий лист (основа для Trade-In процесса)
- `DocLO` - Лист оценки (связан с автомобилем)
- `DocZN` - Заказ-наряд (сервисные работы)
- `DocCarAgreement` - Соглашение о покупке
- `DocCarShipment` - Отгрузка автомобиля

## 🔄 Воронка Trade-In (от контакта до продажи)

### Этапы воронки:

#### 1. **Первичный контакт** (`DocRLK`)
- Создание рабочего листа при обращении клиента
- Типы контактов: Trade-In, выкуп, комиссия
- Фиксация данных клиента и автомобиля
- Интеграция с телефонией (Mango) для записи разговоров
- Онлайн-запись через форму на сайте

**Модель:** `DocRLK`
- Поля: клиент, мастер-консультант, подразделение, тип документа, дата/время
- Статусы: новый, в работе, оценка, согласование, принят, отклонен
- Связи: с интерактивной оценкой, листом оценки, соглашением

#### 2. **Дистанционная оценка** (`RegInteractivOcenka.page_remote`)
- Оценка автомобиля без физического осмотра
- Заполнение данных: пробег, количество владельцев, состояние
- Загрузка фотографий
- Расчет предварительной цены на основе данных
- Назначение аналитика для обработки

**Возможности:**
- Автоматический расчет цены на основе рыночных данных
- Интеграция с Автохаб для получения рыночной цены
- Интеграция с Авито для анализа объявлений
- Расчет с учетом состояния автомобиля

#### 3. **Оценка "До КД"** (Комиссии Дилера)
- Физический осмотр автомобиля оценщиком
- Заполнение детальной информации:
  - Документы (ПТС, СТС, сервисная книжка)
  - Салон (состояние, опции, комплектация)
  - Внешний вид (кузов, лакокрасочное покрытие, дефекты)
  - Комплектность (наличие всех элементов)
  - Колеса (состояние, износ)
  - Тест-драйв (динамика, управляемость)
  - Проверки (диагностика, история)
- Расчет цены с учетом всех факторов
- Назначение аналитика для согласования

**Модели:**
- `RegInteractivOcenkaDocument` - документы
- `RegInteractivOcenkaSalon` - салон
- `RegInteractivOcenkaVnesh` - внешний вид
- `RegInteractivOcenkaComplectnost` - комплектность
- `RegInteractivOcenkaKolesa` - колеса
- `RegInteractivOcenkaTestDrive` - тест-драйв
- `RegInteractivOcenkaProverki` - проверки

#### 4. **Оценка "После КД"**
- Повторная оценка после комиссии дилера
- Уточнение цены с учетом дополнительных факторов
- Корректировка на основе рыночных данных
- Финальное согласование цены

#### 5. **Согласование** (`RegInteractivOcenkaSoglasovanie`)
- Согласование цены приема и цены продажи
- Утверждение аналитиком/руководителем
- Расчет затрат на подготовку
- Расчет итоговой цены с учетом всех факторов

**Поля:**
- `price_reception` - цена приема
- `price_sale` - цена продажи
- `price_after_kd` - цена после КД
- Расчет затрат: подготовка, СС, МЦУ

#### 6. **Принятие автомобиля**
- Создание записи в `RefCarsOrganization`
- Связь с листом оценки (`DocLO`)
- Автоматическое создание плана подготовки (если статус = 8)
- Назначение подразделения и склада

#### 7. **Подготовка к продаже**
- См. раздел "Подготовка автомобилей"

#### 8. **Продажа**
- Создание `DocCarAgreement` - соглашение о покупке
- Создание `DocCarShipment` - отгрузка
- Обновление статуса автомобиля
- Фиксация цены продажи

## 💻 Интерактивная оценка автомобилей

### Модель `RegInteractivOcenka`

**Основные возможности:**

1. **Многоэтапная оценка:**
   - Дистанционная оценка
   - Оценка документов
   - Осмотр салона
   - Осмотр внешнего вида
   - Проверка комплектности
   - Оценка колес
   - Тест-драйв
   - Проверки (диагностика, история)
   - Согласование

2. **Источники данных для расчета цены:**
   - **Автохаб (Avtohub):**
     - Рыночная цена (`hub_avg`)
     - Позиция на рынке (`vRatingPosition`)
     - Количество конкурентов
     - Средние дни продажи
     - Корректировка цены
   
   - **Авито:**
     - Средняя рыночная цена (`avito_price_avg_market_price`)
     - Цена с учетом состояния (`avito_price_avg_condition`)
     - Минимальная/максимальная цена
     - Анализ закрытых сделок
   
   - **КорсАвто (1С):**
     - Оценка на основе внутренних данных (`kors_price`)
     - Анализ продаж компании
     - Средние показатели по складу
     - Средние показатели по продажам
   
   - **Автотека:**
     - История автомобиля
     - Расчет стоимости ремонтов (`autodex`)
     - Проверка на ДТП
     - Проверка на использование в такси/каршеринге

3. **Расчет цены:**
   - Функция `estimations_price_calculation()` - расчет цены на основе выбранного типа
   - Учет затрат на подготовку
   - Учет затрат на ремонт (СС, МЦУ)
   - Защита от убытка
   - Финансовые затраты (процент за дни на складе)
   - Износ автомобиля

4. **Сравнение с авторасчетом:**
   - Сравнение цены оценки с автоматически рассчитанной
   - Классификация: ниже/равно/выше авторасчета
   - Аналитика по конверсии на каждом этапе

  - Статусу
  - Марке/модели
  - Ценовому диапазону
  - Году выпуска
  - Пробегу
  - Варианту управления ценой
  - Этапу УС
- Поиск по VIN, марке, модели
- Сортировка
- Статус "Все" - просмотр всех автомобилей

**Модель:** `RefCarsOrganization`
- `quantity > 0` - автомобили в наличии
- `reserve` - зарезервированные
- `status` - статус автомобиля
- `store` - склад/стоянка

### Каталог автомобилей (`/cars/catalog/`)

**Структура:**
- Иерархия: Марка → Модель → Модификация
- Карточка автомобиля с детальной информацией
- Фотогалерея
- Технические характеристики
- История цен
- История оценок
- Расчетные цены
- Связанные документы

### Склад новых автомобилей vs Склад с пробегом

**Разделение:**
- `is_new = True` - новые автомобили
- `is_new = False` - автомобили с пробегом
- Разные фильтры и представления
- Разная логика ценообразования

## 💰 Ценообразование и переоценка

### Варианты управления ценой (`RefTypeEvaluationCarsOrganization`)

**Типы:**
- Автоматическое управление ценой
- Ручное управление
- Гибридное управление

### Автоматическая переоценка

**Настройки автопереоценки** (`AUTOPRICING_*` в `website/views.py`):

1. **Ценовые диапазоны:** [200, 400, 700, 1200, 2000, 3000, 5000, 5001]
   - Разные правила для разных ценовых категорий

2. **Булевы настройки:**
   - `auto_strategy` - автостратегия цены
   - `auto_active` - активна
   - `lock_eval_change_after_stage` - запрет изменения варианта управления ценой
   - `deny_manual_price` - запрет на ручной ввод
   - `deny_discount` - запрет скидки
   - `no_limit_max_manual` - не ограничивать максимальную ручную цену
   - `reset_manual_prices` - обнуление ручных цен
   - `delay_repricing_new_stage` - отсрочка переоценки в новом этапе
   - `check_price_rule_before_sale` - проверка ценового правила при продаже
   - `check_open_tasks` - проверка не закрытых задач
   - `calc_by_days_in_sale` - расчет по дням в продаже

3. **Настройки Автохаб:**
   - `autohub_mode_kor` - вариант использования данных Автохаб Коррекция
   - `autohub_mode_rdo` - вариант использования данных Автохаб РДО
   - `autohub_mode_test` - вариант использования данных Автохаб Тест прайс
   - `autohub_mode_txt` - вариант использования данных Автохаб ТХТ

4. **Корректировки:**
   - Корректировка для разных источников данных
   - Корректировка для 1С
   - Корректировка для Экспресс-оценки
   - Максимальная скидка за Trade-In
   - Максимальная скидка торг в процентах
   - Маркетинг

5. **Наценки:**
   - Процент наценки базовый
   - Наценки по этапам УС
   - Наценки по ценовым категориям

### История цен

**Модели:**
- `RegRefCarsOrganizationsPrice` - история цен автомобилей
- `RegRefCarsOrganizationsCalculationPrice` - расчетные цены
- `RegEstimationRefCarsOrganizations` - оценки автомобилей

### Переоценка (новый функционал)

**Модели:**
- `RegCarsRepricingHistory` - история переоценок
- `RegCarsRepricingLog` - логи переоценки конкретных автомобилей

**Возможности:**
- Запуск переоценки по подразделению
- Фильтрация по варианту управления ценой
- Автоматический расчет новой цены (функция `calculate_car_price()`)
- История всех переоценок
- Детальные логи по каждому автомобилю
- Статистика: обработано, обновлено, пропущено, ошибок

## 📊 Аналитика и отчетность

### Воронка Trade-In (`/eco/funnel/analytics/`)

**Метрики:**

1. **Общие показатели:**
   - Всего рабочих листов
   - До КД / Дистанционно
   - После КД
   - Принято
   - Конверсия на каждом этапе
   - Целевые показатели с цветовой индикацией:
     - До КД: 70% (красный < 65%, желтый 65-70%, зеленый ≥ 70%)
     - После КД: 50% (красный < 45%, желтый 45-50%, зеленый ≥ 50%)
     - Принято: 80% (красный < 75%, желтый 75-80%, зеленый ≥ 80%)

2. **Сравнение с авторасчетом:**
   - Ниже авторасчета
   - Равно авторасчету
   - Выше авторасчета
   - Для каждого этапа: Дистанционная оценка, До КД, После КД
   - Конверсия и количество принятых для каждой группы

3. **Фильтры:**
   - Период (дата начала - дата окончания)
   - Подразделения (множественный выбор)
   - Группы подразделений
   - Типы приема
   - Оценщики (множественный выбор)
   - Аналитики (множественный выбор)
   - Марки автомобилей

4. **Режим сравнения:**
   - Сравнение двух периодов
   - Сравнение показателей в динамике

### Воронка по аналитикам (`/eco/funnel/analytics/analysts/`)

**Метрики:**
- Производительность каждого аналитика
- Конверсия по этапам
- Количество обработанных оценок
- Средняя цена оценки
- Процент принятых

### Воронка по оценщикам (`/eco/funnel/analytics/appraisers/`)

**Метрики:**
- Производительность каждого оценщика
- Количество проведенных оценок
- Конверсия в принятие
- Качество оценок

### Анализ не принятых (`/eco/funnel/rejected/`)

**Возможности:**
- Анализ причин отклонения
- Статистика по типам отклонений
- Время на каждом этапе до отклонения

### Дашборд (`/korsavto/dashboard/`)

**Общая аналитика:**
- Ключевые показатели
- Динамика продаж
- Анализ склада
- Эффективность подразделений

## 🎯 Ключевые бизнес-процессы

### Процесс 1: Trade-In от контакта до продажи

```
1. Контакт клиента
   ↓
2. Создание DocRLK (рабочий лист)
   ↓
3. Дистанционная оценка (опционально)
   ↓
4. Оценка "До КД" (физический осмотр)
   ↓
5. Оценка "После КД"
   ↓
6. Согласование цены
   ↓
7. Принятие автомобиля → RefCarsOrganization
   ↓
8. Автоматическое создание плана подготовки
   ↓
9. Подготовка автомобиля
   ↓
10. Выставление на продажу
    ↓
11. Продажа → DocCarAgreement → DocCarShipment
```

### Процесс 2: Управление ценой

```
1. Автомобиль на складе (RefCarsOrganization)
   ↓
2. Определение варианта управления ценой (evaluation)
   ↓
3. Автоматическая переоценка по расписанию
   ИЛИ
   Ручная переоценка
   ↓
4. Расчет новой цены на основе:
   - Рыночных данных (Автохаб, Авито)
   - Внутренних данных (1С, КорсАвто)
   - Этапа УС
   - Дней на складе
   - Ценовой категории
   ↓
5. Обновление цены
   ↓
6. История переоценок (RegCarsRepricingHistory)
```

### Процесс 3: Подготовка автомобиля

```
1. Принятие автомобиля
   ↓
2. Автоматическое создание CarPreparation
   (на основе работ из оценки)
   ↓
3. Назначение ответственного
   ↓
4. Выполнение работ по этапам:
   - Приемка
   - Диагностика
   - Ремонт
   - Мойка
   - Полировка
   - Контроль качества
   ↓
5. Фотофиксация этапов
   ↓
6. Чек-лист качества
   ↓
7. Утверждение подготовки
   ↓
8. Готов к продаже
```

## 📈 Метрики и KPI

### Метрики воронки Trade-In:
- Конверсия: контакт → дистанционная оценка
- Конверсия: дистанционная оценка → до КД
- Конверсия: до КД → после КД
- Конверсия: после КД → принято
- Общая конверсия: контакт → продажа
- Среднее время на каждом этапе
- Процент отклонений на каждом этапе

### Метрики ценообразования:
- Средняя цена оценки
- Средняя цена продажи
- Маржинальность
- Дни на складе
- Скорость продажи
- Эффективность переоценки

### Метрики подготовки:
- Среднее время подготовки
- Процент автомобилей, прошедших контроль качества
- Средняя стоимость подготовки
- Загрузка исполнителей

## 🔐 Безопасность и права доступа

### Роли пользователей:
- Оценщик - может проводить оценки
- Аналитик - может согласовывать цены
- Мастер-консультант - может создавать рабочие листы
- Менеджер по продажам - может работать с соглашениями
- Администратор - полный доступ

### Профили (`Profiles`):
- `eco` - доступ к интерактивной оценке
- `eco_visible` - просмотр аналитики
- Различные настройки доступа к разделам

- История переоценок
- Детальные логи

## 📝 Заключение

Портал представляет собой комплексную систему управления бизнесом автомобилей с пробегом, охватывающую весь цикл от первого контакта с клиентом до продажи автомобиля. Система включает:

✅ Полную воронку Trade-In с детальной аналитикой
✅ Многоэтапную интерактивную оценку
✅ Автоматическое ценообразование на основе рыночных данных
✅ Управление подготовкой автомобилей
✅ Интеграции с внешними сервисами
✅ Мобильные возможности
✅ Детальную аналитику и отчетность
✅ Автоматизацию бизнес-процессов

Система готова к масштабированию и добавлению новых функций, таких как переоценка автомобилей и выгрузка на площадки.
