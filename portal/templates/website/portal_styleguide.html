Соглашения (имена и скоуп)

Полный текст для репозитория: файл docs/portal-ui-conventions.md в корне проекта.

  • Скоуп: весь пользовательский контент страницы — внутри portal-page; заголовок экрана — portal-header; белые секции — portal-panel.
  • Префикс portal-: общие блоки макета и метрики с суффиксом -portal (metric-card-label-portal и т.д.).
  • Наследие: metric-card / metric-card-label без суффикса — старые экраны; в новых шаблонах предпочитать вариант с -portal.
  • Стили: не дублировать оформление в <style> шаблонов — только portal-style.css, с прицелом на скоуп (.portal-panel .table, а не голый table).
  • Имена: kebab-case; предметные карточки — говорящие имена (car-spec-card, settings-chip).
  • Bootstrap — сетка, кнопки, алерты, формы; файл портала дополняет, а не заменяет систему классов.
