# Автоматическое создание плана подготовки

## Описание

При проведении интерактивной оценки (`RegInteractivOcenka`) со статусом 8 автоматически создается план работ по подготовке автомобиля на основе работ из таблиц:
- `RegEstimationMCU` (Кузовной цех)
- `RegEstimationSS` (Слесарный цех)  
- `RegEstimationPodgotovka` (Подготовка)

## Как это работает

1. При сохранении `RegInteractivOcenka` с `status.id = 8` запускается сигнал
2. Сигнал проверяет наличие работ в таблицах оценок
3. Если работы найдены, создается `CarPreparation` с соответствующими `CarPreparationWorkItem`
4. Работы группируются по этапам:
   - "Кузовной цех" - для работ из `RegEstimationMCU`
   - "Слесарный цех" - для работ из `RegEstimationSS`
   - "Подготовка" - для работ из `RegEstimationPodgotovka`

## Что передается

Для каждой работы:
- `name` - название работы
- `normo` - нормочасы (конвертируются в минуты для `estimated_time`)
- `price_kors` - стоимость (используется в `cost`)

## Настройка

Сигнал регистрируется в `register/apps.py`:
```python
def ready(self):
    import register.signals  # Регистрируем сигналы
```

## Требования

- Автомобиль должен существовать в `RefCarsOrganization` (поиск по VIN)
- В `rlk` должно быть указано подразделение
- Работы должны быть с заполненным полем `name`

## Защита от дублирования

Проверяется наличие существующей подготовки для данного `rlk`. Если подготовка уже существует, новая не создается.

## Логирование

Все действия логируются в консоль через `print()`. При ошибках выводятся:
- Описание ошибки
- Стек вызовов (traceback)
