# Приложение "Классифайды"

Приложение для управления выгрузкой автомобилей на различные площадки в формате XML.

## Основные возможности

1. **Настройка выгрузки** - создание и редактирование настроек выгрузки для разных площадок
2. **Фильтрация автомобилей** - гибкие фильтры для выбора автомобилей для выгрузки
3. **Маппинг полей** - настройка соответствия полей автомобиля полям площадки
4. **Генерация XML** - автоматическая генерация XML файлов по шаблонам
5. **История выгрузок** - полная история всех выгрузок с детализацией
6. **Автоматизация** - возможность настройки автоматической выгрузки по расписанию

## Модели

- `RefClassifiedsPlatform` - справочник площадок для выгрузки
- `ClassifiedsExportConfig` - настройки выгрузки
- `ClassifiedsFieldMapping` - маппинг полей автомобиля на поля площадки
- `ClassifiedsExportHistory` - история выгрузок
- `ClassifiedsExportLog` - логи выгрузки конкретных автомобилей

## Использование

1. Создайте площадку в админ-панели (`RefClassifiedsPlatform`)
2. Создайте настройку выгрузки (`ClassifiedsExportConfig`)
3. Настройте фильтры и маппинг полей
4. Запустите выгрузку вручную или настройте автоматическую

## API

- `/classifieds/` - список настроек
- `/classifieds/config/<id>/` - детали настройки
- `/classifieds/config/<id>/export/` - запуск выгрузки
- `/classifieds/history/` - история выгрузок
