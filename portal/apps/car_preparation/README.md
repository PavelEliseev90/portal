# Модуль подготовки автомобилей

Модуль для автоматизации и мобильности работы отдела подготовки автомобилей.

## Основные возможности

### 1. Управление этапами подготовки
- Определение этапов подготовки (мойка, диагностика, ремонт, полировка и т.д.)
- Настройка последовательности этапов
- Оценка времени на каждый этап

### 2. Управление видами работ
- Каталог работ по подготовке
- Привязка работ к этапам
- Настройка обязательности работ
- Планирование времени и стоимости

### 3. Процесс подготовки
- Создание задания на подготовку автомобиля
- Назначение ответственных и исполнителей
- Контроль выполнения работ
- Отслеживание прогресса (процент выполнения)
- Расчет времени и стоимости

### 4. Мобильность
- QR-коды для быстрого доступа к заданиям
- Мобильный интерфейс для выполнения работ
- Фотофиксация этапов
- Автономная работа с синхронизацией

### 5. Контроль качества
- Чек-листы качества подготовки
- Оценка по критериям:
  - Общая оценка качества
  - Чистота
  - Комплектность
  - Отсутствие дефектов
- Подпись инспектора качества
- Утверждение подготовки

### 6. Шаблоны подготовки
- Создание шаблонов для разных типов автомобилей
- Настройка работ по шаблону
- Автоматическое применение шаблона при создании подготовки

### 7. Фотофиксация
- Прикрепление фотографий к работам
- Геолокация фотографий
- Информация об устройстве

### 8. Уведомления
- Уведомления о создании подготовки
- Уведомления об изменении статуса
- Уведомления о просрочке
- Уведомления о завершении

### 9. Отчетность
- Отчеты о подготовке автомобилей
- История изменений
- Статистика по времени и стоимости

## Структура моделей

### Справочники
- `RefCarPreparationStage` - Этапы подготовки
- `RefCarPreparationWork` - Виды работ
- `RefCarPreparationStatus` - Статусы подготовки

### Основные модели
- `CarPreparation` - Подготовка автомобиля
- `CarPreparationWorkItem` - Пункт работы
- `CarPreparationPhoto` - Фотографии
- `CarPreparationChecklist` - Чек-лист качества
- `CarPreparationTemplate` - Шаблон подготовки
- `CarPreparationHistory` - История изменений
- `CarPreparationNotification` - Уведомления

## Установка

1. Добавьте приложение в `INSTALLED_APPS` в `settings.py`:
```python
INSTALLED_APPS = [
    ...
    'car_preparation.apps.CarPreparationConfig',
    ...
]
```

2. Выполните миграции:
```bash
python manage.py makemigrations car_preparation
python manage.py migrate car_preparation
```

3. Создайте начальные данные (этапы, работы, статусы) через админ-панель Django

## Использование

### Создание подготовки автомобиля

```python
from car_preparation.models import CarPreparation, RefCarPreparationStatus

# Создание подготовки
preparation = CarPreparation.objects.create(
    car=car_organization,
    unit=unit,
    status=RefCarPreparationStatus.objects.get(code='new'),
    responsible=staff_member,
    comment_initial='Требуется полная подготовка'
)
```

### Применение шаблона

```python
from car_preparation.models import CarPreparationTemplate

template = CarPreparationTemplate.objects.get(is_default=True)
template.apply_to_preparation(preparation)
```

### Мобильный интерфейс

Доступ через QR-код:
```
/car_preparation/mobile/{preparation.id}/
```

## API Endpoints

- `GET /api/car_preparation/preparations/` - Список подготовок
- `POST /api/car_preparation/preparations/` - Создание подготовки
- `GET /api/car_preparation/preparations/{id}/` - Детали подготовки
- `POST /api/car_preparation/preparations/{id}/complete/` - Завершение подготовки
- `POST /api/car_preparation/work_items/{id}/` - Обновление работы
- `POST /api/car_preparation/photos/` - Загрузка фото

## Интеграция с мобильным приложением

Модуль поддерживает интеграцию с мобильными приложениями:
- REST API для синхронизации данных
- Push-уведомления
- Офлайн-режим с последующей синхронизацией
- Загрузка фотографий

## Администрирование

Все модели доступны в админ-панели Django для управления справочниками и подготовки автомобилей.
