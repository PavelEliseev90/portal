## Запуск приложения

```bash
cd mobile_app_flutter
flutter pub get
flutter run
```

## API Endpoints

Все endpoints доступны по адресу:
```
https://ah.kors-group.com/api/a/v2/
```

WebSocket:
```
wss://ah.kors-group.com/ws/rlk_{rlk_id}/
```

## Примечания

- Все данные сохраняются локально при отсутствии интернета
- Синхронизация происходит автоматически при появлении интернета
- Веб-сокет автоматически переподключается при разрыве связи
- Приложение готово к дальнейшей разработке и тестированию
