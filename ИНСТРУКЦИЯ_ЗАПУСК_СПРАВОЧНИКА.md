# 🚀 Инструкция по запуску справочника диагностики

## Шаг 1: Миграции базы данных

Выполните команды для создания и применения миграций:

```bash
python manage.py makemigrations register
python manage.py migrate
```

Это создаст таблицы в базе данных:
- `diagnostic_reference_category` - категории справочника
- `diagnostic_reference_item` - элементы справочника
- `diagnostic_reference_selection` - выбранные элементы

## Шаг 2: Импорт данных для категории "Двигатель"

Импортируйте предзаполненные данные:

```bash
python manage.py import_diagnostic_reference
```

Эта команда:
- Создаст категорию "Двигатель" (код: `engine`)
- Импортирует 10 элементов справочника из вашего примера

## Шаг 3: Создание остальных категорий (опционально)

Через Django Admin (`/admin/register/diagnosticreferencecategory/`) создайте категории для остальных разделов:

| Код категории | Название |
|--------------|----------|
| `engine` | Двигатель ✅ (уже создана) |
| `gear` | Коробка передач |
| `brake` | Тормозная система |
| `suspension` | Подвеска |
| `system_og` | Система выпуска ОГ |
| `wheel` | Рулевое управление |
| `conditioner` | Кондиционер |
| `turbo` | Турбина |
| `drive` | Полный привод |
| `to` | ТО |
| `subframe` | Подрамник |
| `airbag` | Подушка безопасности |

**Важно:** Код категории должен точно соответствовать указанному в таблице!

## Шаг 4: Интеграция в шаблон lo_v3.html

### 4.1 Подключение модального окна

Откройте файл `portal/templates/lo/lo_v3.html` и в конце файла (перед `{% endblock %}`) добавьте:

```django
{% include 'lo/diagnostic_reference_modal.html' %}
```

**Пример для "Двигатель":**
```html

    data-bs-target="#diagnosticReferenceModal"
    data-category="engine"
    title="Открыть справочник диагностики"
    style="color: #002a5a; text-decoration: none;"

    <i class="bi bi-info-circle"></i>
```

- Подвеска → `data-category="suspension"`
- Система выпуска ОГ → `data-category="system_og"`

### 4.4 Инициализация выбранных элементов (опционально)

Если нужно загружать уже выбранные элементы при открытии формы, добавьте скрипт после подключения модального окна:

```javascript
<script>
$(document).ready(function() {
  // Загружаем уже выбранные элементы из params
  {% if params.selected_references %}
    {% for category_code, item_ids in params.selected_references.items %}
      $('#selected_reference_items_{{ category_code }}').val('{{ item_ids|join:"," }}');
    {% endfor %}
  {% endif %}
});
</script>
```

## Шаг 5: Проверка работы

1. **Проверьте API:**
   - Откройте в браузере: `http://your-domain/register/diagnostic_reference/?category=engine`
   - Должен вернуться JSON со списком элементов для категории "Двигатель"

2. **Проверьте в интерфейсе:**
   - Откройте страницу с диагностикой (lo_v3.html)
   - Рядом с разделом "Двигатель" должна появиться иконка подсказки (ℹ️)
   - При клике на иконку должно открыться модальное окно со справочником
   - Можно выбрать элементы и они должны сохраниться при сохранении формы

## ⚠️ Важные замечания

1. **Коды категорий должны точно совпадать** с указанными в `data-category` атрибутах
2. **Bootstrap Icons** должны быть подключены (класс `bi bi-info-circle`)
3. **jQuery** должен быть подключен для работы модального окна
4. **Bootstrap 5** должен быть подключен для модальных окон

## 🐛 Решение проблем

### Проблема: Модальное окно не открывается
- Проверьте, что Bootstrap 5 подключен
- Проверьте консоль браузера на наличие ошибок JavaScript
- Убедитесь, что jQuery подключен

### Проблема: API возвращает 404
- Проверьте, что URL включен в `portal/urls.py`: `path('register/', include('register.urls'))`
- Проверьте, что категория создана в базе данных с правильным кодом

### Проблема: Данные не сохраняются
- Проверьте, что скрытые поля добавлены в форму
- Проверьте обработку в `eco/views.py` (функция `doc`)
- Проверьте консоль браузера на наличие ошибок
