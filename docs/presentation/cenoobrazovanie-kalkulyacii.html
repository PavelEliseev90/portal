Слайд 1

Ценообразование новых автомобилей и калькуляции

Модуль портала для контроля минимальной кумулятивной маржи (КМ) на складе новых АМ и для коммерческого расчёта сделки по рабочему листу отдела продаж.

ЦенообразованиеПравила КМ, карточка каждого авто
КалькуляцияРасчёт сделки, КВП, акции
АналитикаСклад, продажи, сравнение с порогом КМ
Эта презентация в портале
Слайд 2

Зачем это нужно

  • Единые правила маржи по брендам и этапам цены для всей сети дилерских центров.
  • Контроль скидок — менеджер видит минимальный КМ до согласования сделки.
  • Прозрачность экономики — КВП и детализация по статьям в калькуляции.
  • Контекст для решения — склад по моделям и средняя ВП подразделения за месяц.

Слайд 3

Как связаны разделы

Настройки КМ → Карточка авто → Калькуляция → Соглашение / отгрузка

КМ (кумулятивная маржа) — минимальный порог маржи в рублях. Считается автоматически по складу бренда, по продажам за месяц (Power BI) или задаётся вручную на автомобиле.

ТипИсточникКогда активен
1 — по складуКМ бренда ÷ средняя РРЦ склада × индекс этапаПо умолчанию
2 — по продажамСредняя ВП розницы за месяц по брендуЕсли выше типа 1
3 — ручнойПоле «мин. КМ» на автоЕсли задано (≠ 0)

Слайд 11

Калькуляция одной сделки

URL: /cars/deal/calculation/{id}/

  • Рабочий лист ОП: клиент, менеджер, подразделение, события РЛ
  • Автомобиль: VIN, себестоимость, ссылка на ценообразование
  • Применённые акции (сворачиваемый блок)
  • Расчётные данные — КВП и детализация
  • Справа: мин. КМ по правилу и итоги калькуляции
Слайд 12

Аналитика внутри калькуляции

Склад

Две круговые диаграммы: новые АМ в наличии по моделям марки — в подразделении калькуляции и по всей сети.

Продажи подразделения

За текущий месяц: карточки ВП (маржа, ОПФУ, trade-in, шины, работы, запчасти, гос. рег.) и график средней ВП по моделям с сегментами:

  • Железо — маржа без НДС
  • ДОП — работы, ЗЧ, шины, гос. рег.
  • ОПФУ — VPOPFU
  • ТИ — trade-in по плану
Слайд 13

Типовой сценарий менеджера

  1. Рабочий лист ОП → создание / открытие калькуляции по автомобилю.
  2. Проверка мин. КМ в правой колонке — сравнение с планируемым КВП.
  3. Просмотр акций и корректировка условий сделки.
  4. Оценка склада и продаж ДЦ — обоснование скидки.
  5. При необходимости — переход в ценообразование авто для ручного КМ или истории.
  6. Оформление соглашения и отгрузки (контроль в реестре калькуляций).
