Документация проекта (по приложениям)

Эта документация формируется итеративно. По каждому приложению создаётся отдельная HTML-страница с описанием: связей моделей, функционала и точек входа (views/urls). Сейчас подготовлены первые страницы (в первую очередь блок, который мы уже трогали).

estimations

Интерактивные оценки (осмотры/страницы оценки), включая страницу приёмки 2-го комплекта колёс (2КК).

register

Хранение сущностей интерактивных оценок и связанных данных (Reg* модели, включая 2КК приёмку и файлы).

refs

Справочники (марки, размеры шин/дисков, статусы и т.д.), используемые почти во всех формах.

api

REST/служебные endpoint-ы: мобильные v1/v2, обмен с 1С, swagger, интеграционные методы и сервисные операции.

Остальные приложения

Список приложений берётся из INSTALLED_APPS в portal/settings.py. Остальные страницы буду добавлять по очереди.

Подтверди, пожалуйста, с чего продолжать углубляться в детализацию: по app страницам в порядке или по твоей очереди (например: сначала api, потом avtosalon).
