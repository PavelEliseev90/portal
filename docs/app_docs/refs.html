Приложение: refs

Назначение: справочники (марки, радиусы, статусы, типы и т.д.). Почти все формы проекта опираются на refs.

Роль приложения refs в архитектуре

  • Единый источник справочников: значения, которые нельзя “хардкодить” в бизнес-моделях, вынесены в refs.
  • Нормализация данных: большинство доменных моделей используют FK на refs вместо свободного текста.
  • Управление через admin: refs обеспечивает гибкую настройку без переписывания бизнес-кода.

Ключевые группы справочников

ГруппаПримеры моделейГде используются
Шины/диски RefMarkTyres, RefWidthTyres, RefProfileTyres, RefRadius, RefSezonTyres, RefTypeDisk, RefEtDisk, RefDiaDisk, RefPsdDisk Оценка/приёмка 2КК, карточки колёс, блоки диагностики и формы согласования комплектации.
Оргструктура RefUnit, RefOrganization, RefFilial, RefStore Фильтры списков, маршрутизация задач, аналитика и отчёты по подразделениям.
Статусы и этапы RefStatusEstimation, RefTypeEvaluationCarsOrganization, и др. Сценарии оценки, ценообразование, workflow согласования.
Каталожные авто-данные AutoruMark, AutoruModel, AutoruModification, AutoruComplectation Старт оценки, выбор модификации, API каталогов mobile v2.

В контексте 2КК (подробно)

  • RefMarkTyres, RefWidthTyres, RefProfileTyres, RefRadius, RefSezonTyres
  • RefTypeDisk, RefEtDisk, RefDiaDisk, RefPsdDisk
  • Используются в модели RegInteractivOcenkaKolesaReception и в редактировании полей приёмки 2КК через searchable Select2.
  • Те же типы справочников используются на основной странице колёс (RegInteractivOcenkaKolesa) при фиксации данных оценки.

Связки с другими приложениями

  • register/estimations: основные потребители refs в сценариях оценки и её этапов.
  • api: отдаёт и принимает значения, основанные на refs (каталоги, типы, статусы).
  • avtosalon/prices: управление складом, ценой и аналитикой использует оргструктуру и статусы из refs.
  • documents: рабочие листы и документы привязаны к подразделениям/типам из refs.
Следующий шаг по refs: можно сделать “словарь моделей” (каждая модель refs + поля + порядок сортировки + где читается/пишется).
