# Инструкция по интеграции справочника диагностики в lo_v3.html

## Шаг 1: Подключение модального окна

В конце файла `lo_v3.html` (перед закрывающим тегом `</body>` или `{% endblock %}`) добавьте:

```django
{% include 'lo/diagnostic_reference_modal.html' %}
```

## Шаг 2: Добавление иконок подсказок к разделам диагностики

Для каждого раздела диагностики (Двигатель, КПП, Тормозная система и т.д.) нужно добавить иконку подсказки рядом с заголовком.

### Пример для раздела "Двигатель":

Найдите строку с заголовком раздела (например, `<h6>Двигатель</h6>` или подобное) и добавьте иконку:

```html
<h6>
  <span class="icon-mbri-credit-card"></span> Двигатель
  <button 
    type="button" 
    class="btn btn-sm btn-link p-0 ms-2 diagnostic-reference-icon" 
    data-bs-toggle="modal" 
    data-bs-target="#diagnosticReferenceModal"
    data-category="engine"
    title="Открыть справочник диагностики"
    style="color: #002a5a; text-decoration: none;"
  >
    <i class="bi bi-info-circle"></i>
  </button>
</h6>
```

### Маппинг категорий:

Используйте следующие коды категорий для каждого раздела:

- **Двигатель** → `data-category="engine"`
- **Коробка передач (КПП)** → `data-category="gear"`
- **Тормозная система** → `data-category="brake"`
- **Подвеска** → `data-category="suspension"`
- **Система выпуска ОГ** → `data-category="system_og"`
- **Рулевое управление** → `data-category="wheel"`
- **Кондиционер** → `data-category="conditioner"`
- **Турбина** → `data-category="turbo"`
- **Полный привод** → `data-category="drive"`
- **ТО** → `data-category="to"`
- **Подрамник** → `data-category="subframe"`
- **Подушка безопасности** → `data-category="airbag"`

## Шаг 4: Загрузка уже выбранных элементов при открытии формы

Если нужно показать уже выбранные элементы при загрузке страницы, добавьте в view передачу данных о выбранных элементах:

```python
# В view (eco/views.py, функция doc)
if reg_interactiv_ocenka.page_test_drive:
    selected_references = {}
    selections = DiagnosticReferenceSelection.objects.filter(
        test_drive=reg_interactiv_ocenka.page_test_drive
    ).select_related('reference_item')
    
    for selection in selections:
        if selection.category_code not in selected_references:
            selected_references[selection.category_code] = []
        selected_references[selection.category_code].append(selection.reference_item.id)
    
    params['selected_references'] = selected_references
```

И в шаблоне добавьте инициализацию:

```javascript
// В конце страницы, после подключения модального окна
$(document).ready(function() {
  // Загружаем уже выбранные элементы
  {% if params.selected_references %}
    {% for category_code, item_ids in params.selected_references.items %}
      $('#selected_reference_items_{{ category_code }}').val('{{ item_ids|join:"," }}');
    {% endfor %}
  {% endif %}
});
```

## Проверка работы

1. Убедитесь, что модальное окно подключается: `{% include 'lo/diagnostic_reference_modal.html' %}`
2. Проверьте, что иконки подсказок появляются рядом с каждым разделом
3. При клике на иконку должно открываться модальное окно со справочником
4. После выбора элементов и нажатия "Применить выбранные", значения должны сохраняться в скрытые поля
5. При сохранении формы выбранные элементы должны сохраняться в базу данных
