Через Django Admin создайте категории:

- `drive` - Полный привод

- `airbag` - Подушка безопасности

### 4. Интеграция в lo_v3.html

#### 4.1 Подключение модального окна
В конце файла `lo_v3.html` (перед `{% endblock %}`) добавьте:
```django
{% include 'lo/diagnostic_reference_modal.html' %}
```

#### 4.2 Добавление иконок подсказок
Для каждого раздела диагностики добавьте иконку рядом с заголовком:

**Шаблон кода:**
```html
<h6>
  <span class="icon-mbri-credit-card"></span> [Название раздела]
  <button 
    type="button" 
    class="btn btn-sm btn-link p-0 ms-2 diagnostic-reference-icon" 
    data-bs-toggle="modal" 
    data-bs-target="#diagnosticReferenceModal"
    data-category="[код_категории]"
    title="Открыть справочник диагностики"
    style="color: #002a5a; text-decoration: none;"
  >
    <i class="bi bi-info-circle"></i>
  </button>
</h6>
```

**Разделы и их коды:**
- Двигатель → `data-category="engine"`
- Коробка передач → `data-category="gear"`
- Тормозная система → `data-category="brake"`
- Подвеска → `data-category="suspension"`
- Система выпуска ОГ → `data-category="system_og"`
- Рулевое управление → `data-category="wheel"`
- Кондиционер → `data-category="conditioner"`
- Турбина → `data-category="turbo"`
- Полный привод → `data-category="drive"`
- ТО → `data-category="to"`
- Подрамник → `data-category="subframe"`
- Подушка безопасности → `data-category="airbag"`

## 🎯 Результат

После выполнения всех шагов:
1. Рядом с каждым разделом диагностики будет иконка подсказки
2. При клике откроется модальное окно со справочником для этого раздела
3. Можно выбрать элементы справочника
4. Выбранные элементы сохраняются при сохранении формы
5. При следующем открытии выбранные элементы будут загружены автоматически
