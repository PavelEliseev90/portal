Внутренний инструмент

Рабочее место дилера на аукционе Maxposter

Единый экран: лоты аукциона, сравнение со складом и продажами группы Kors, расчёт выкупа и ставки — без ручного обхода сайта.

Kors Group · 2026

Проблема

Что было до решения

  • Лоты на аукционе смотрятся вручную на сайте Maxposter — много вкладок и кликов.
  • Расчёт выкупа, сравнение со складом и продажами сети, минимальной ставкой — в разных системах и «в голове» менеджера.
  • Ставка требует входа на сайт, поиска лота, ввода суммы — медленно при большом потоке.
  • Нет единой таблицы с фильтрами, подсветкой «выгодно / риск» и историей обновлений.
Решение

Что сделано

Веб-приложение + сервер автоматизации на базе Playwright и API Maxposter.

Портал / браузер → Таблица + бейджи склад / продажи → Расчёт выкупа (Kors API) → Ставка через API

Продажи группы компаний

Возможно, продавец готов немного уступить

Помогает понять потенциал торга и типичную динамику сделок в группе.

Особенности реализации

Технические плюсы

  • API вместо кликов по UI для ставок — стабильнее, быстрее, проще сопровождать.
  • Очередь обновлений — нет конфликтов при автообновлении и ручной перезагрузке.
  • Кэш расчётов — повторный расчёт выкупа без лишних запросов.
  • Безопасный режим — без логина/пароля обновление просто пропускается, приложение не падает.
  • Готовность к порталу — UI и API можно вынести в корпоративный backend с фоновыми задачами.
Эффект для компании

Бизнес-результат

Скорость

Меньше времени на один лот: всё в таблице, ставка из модалки, без лишних переходов по сайту.

Качество решений

Сравнение со складом и продажами группы, расчёт выкупа и подсветка строк снижают риск переплаты и «чужих» лотов.

Масштабирование

На портале — итоги торгов, история и автоматический рабочий лист для связи с клиентом после выигрыша лота.

Снижение ошибок

Явная сумма ставки, min/step в таблице, лог запроса/ответа API — меньше «случайных» кликов.

Дорожная карта

Следующие шаги

  • Интеграция в корпоративный портал — единый вход, роли, аудит ставок.
  • Итоги торгов на портале — победа / проигрыш, финальная цена, история по лотам.
  • Авто рабочий лист — при выигрыше создаётся задача менеджеру для связи с клиентом (продавцом).
  • База данных вместо JSON-файла — история, отчёты, аналитика.
  • Фоновые задачи — worker + статус «обновление идёт» для всей команды.
  • Хранение кредов в защищённом хранилище, не в браузере.
  • Правила автоставок — лимиты, стратегии от minAvailableBid / расчёта.
