**Важно:** В view (`eco/views.py`, функция `doc`) нужно передать выбранные элементы справочника в `params`:

```python
# Получаем выбранные элементы справочника
selected_references = {}
for category_code in ['engine', 'gear', 'brake', 'suspension', 'system_og', 
                      'wheel', 'conditioner', 'turbo', 'drive', 'to', 
                      'subframe', 'airbag']:
    selections = DiagnosticReferenceSelection.objects.filter(
        test_drive=test_drive,
        category_code=category_code
    ).select_related('reference_item')
    
    if selections.exists():
        selected_references[category_code] = [
            {
                'id': sel.reference_item.id,
                'title': sel.reference_item.title,
                'description': sel.reference_item.description,
                'observation_zones': sel.reference_item.observation_zones,
                'possible_causes': sel.reference_item.possible_causes,
                'consequences': sel.reference_item.consequences,
                'additional_info': sel.reference_item.additional_info,
            }
            for sel in selections
        ]

params['selected_references'] = selected_references
```

## Как это работает:

1. **Выбор элементов**: Пользователь кликает на иконку ℹ️ рядом с разделом диагностики
2. **Модальное окно**: Открывается модальное окно со справочником для этого раздела
3. **Выбор**: Пользователь выбирает нужные элементы (карточки свернуты, можно раскрыть для просмотра деталей)
4. **Счетчик**: Рядом с иконкой показывается количество выбранных элементов
5. **Сохранение**: При сохранении формы выбранные элементы сохраняются в базу данных
6. **Отображение**: В блоке информации для клиента выводятся все выбранные элементы с красивым оформлением
