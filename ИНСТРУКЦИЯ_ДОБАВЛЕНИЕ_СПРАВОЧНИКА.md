# Инструкция по добавлению справочника диагностики в шаблон lo_v3.html

## Шаг 1: Включить модальное окно

В конец шаблона `lo_v3.html` (перед `{% endblock %}`) добавить:

```django
{% include 'lo/diagnostic_reference_modal.html' %}
```

## Шаг 2: Добавить иконки подсказок рядом с заголовками разделов диагностики

Для каждого раздела диагностики (Двигатель, КПП, Тормозная система и т.д.) нужно добавить иконку подсказки рядом с заголовком.

### Пример для раздела "Двигатель":

**Найти в шаблоне:**
```html
<h6><span class="icon-mbri-credit-card"></span> Двигатель</h6>
```

**Заменить на:**
```html
<h6>
  <span class="icon-mbri-credit-card"></span> Двигатель
  <i class="bi bi-info-circle diagnostic-reference-icon" 
     data-bs-toggle="modal" 
     data-bs-target="#diagnosticReferenceModal"
     data-category="engine"
     title="Открыть справочник диагностики"></i>
</h6>
```

## Шаг 3: Проверка

После добавления:
1. Откройте страницу интерактивной оценки
2. Перейдите в раздел диагностики (тест-драйв)
3. Рядом с каждым разделом должна появиться иконка подсказки (синий кружок с "i")
4. При клике на иконку должно открываться модальное окно со справочником для соответствующего раздела

## Примечания

- Иконка использует Bootstrap Icons (`bi bi-info-circle`)
- Стили для иконки уже включены в `diagnostic_reference_modal.html`
- Модальное окно автоматически загружает данные для выбранной категории
- Выбранные элементы сохраняются в скрытых полях формы и отправляются при сохранении
